🌟 Why JourneyLog?

In reservation systems, 3rd-party APIs (GDS, Wholesalers, Suppliers) change prices and availability in milliseconds. When a customer claims a price mismatch or a booking fails, you need evidence.

🔒

Session Isolation

Every visitor gets their own unique JSON log file. No mixed data.

📁

Folder-Wise Logic

Automatically group logs into categories like /search, /api-responses, or /bookings.

⚡

Hybrid Ready

Works seamlessly with Web (Sessions) and Stateless APIs (Headers).

🛡️

Security First

Built-in Global Masking recursively hides sensitive PII (passwords, API keys, tokens).

Quick Installation

1

Install via Composer

composer require mhrshuvo/journey-log
2

Add Middleware

// In bootstrap/app.php (Laravel 11)
->withMiddleware(function (Middleware $middleware) {
    $middleware->web(append: ['journey-log']);
})
3

Start Tracking!

// Automatic tracking is now enabled
// Custom logging:
journey_log('purchase', 'User completed purchase', [
    'product_id' => 123,
    'amount' => 99.99
]);

Usage Examples

// Automatic journey tracking
Route::middleware(['journey-log'])->group(function () {
    Route::get('/', [HomeController::class, 'index']);
    Route::get('/products', [ProductController::class, 'index']);
    Route::post('/search', [SearchController::class, 'search']);
});

// Custom journey logging
journey_log('search', 'User searched for products', [
    'query' => 'laptop',
    'filters' => ['brand' => 'apple'],
    'results_count' => 25
]);

journey_log('checkout', 'User completed checkout', [
    'total_amount' => 1299.99,
    'payment_method' => 'credit_card',
    'items_count' => 3
]);
// Sensitive data masking (automatic)
journey_log('payment', 'Processing payment', [
    'user_id' => 123,
    'amount' => 99.99,
    'card_number' => '1234-5678-9012-3456',  // Automatically masked
    'cvv' => '123',                          // Automatically masked
    'api_key' => 'sk_live_abc123xyz',        // Automatically masked
    'transaction_id' => 'txn_456789'         // Remains visible
]);

// Logged output (sensitive data protected)
{
  "message": "Processing payment",
  "context": {
    "user_id": 123,
    "amount": 99.99,
    "card_number": "********",
    "cvv": "********",
    "api_key": "********",
    "transaction_id": "txn_456789"
  }
}

// Default masked fields:
// password, password_confirmation, cvv, card_number,
// api_key, auth_token, access_token, secret

// Customize in config/journeylog.php
'mask_fields' => [
    'password',
    'ssn',              // Add custom field
    'bank_account',     // Add custom field
]
# API requests with custom journey ID
curl -H "X-Journey-ID: user-abc123" \
     https://yourapp.com/api/products

# Journey persists across API calls
curl -H "X-Journey-ID: user-abc123" \
     -X POST https://yourapp.com/api/cart/add \
     -d '{"product_id": 123}'

# View logs organized by journey ID
ls storage/logs/journeys/
# └── api_request/
#     ├── journey-user-abc123.json
#     └── journey-guest-xyz789.json
// Enable dashboard in .env
JOURNEY_LOG_SUMMARY_ENABLED=true

// Visit dashboard
https://yourapp.com/journey-log

// Configure cleanup
JOURNEY_LOG_AUTO_CLEANUP_ENABLED=true
JOURNEY_LOG_CLEANUP_RETENTION_HOURS=24

// Manual cleanup
php artisan journey-log:cleanup --dry-run
